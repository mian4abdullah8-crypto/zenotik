Latest Error

Abhi koi error record nahi hua.

Login / Google sign-in error

Firebase Console → Authentication → Sign-in method mein Email/Password aur Google enable karein. Authentication → Settings → Authorized domains mein apna GitHub Pages domain add karein. Google popup block ho to browser popup allow karein.

Photo, video, story ya DP upload error

Firebase Console → Storage mein bucket setup karein aur firebaseConfig.storageBucket ka naam match karein. Storage Rules publish karein. Post/story 100 MB se chhoti aur DP 5 MB se chhoti honi chahiye. Upload ke liye signed in hona zaroori hai.

Posts ya stories load/save nahi hote

Firebase Console → Firestore Database check karein. Database bana ho aur Firestore Rules signed-in users ko required read/create access deti hon. Exact error code bhi check karein.

Camera / Live error

Website HTTPS par kholein aur browser ko camera/microphone permission dein. Is app ka Live section local camera preview hai, public broadcast nahi.

News load nahi hoti

Internet check karein aur dobara Load News dabayein. News service temporarily unavailable ho sakti hai.

Firebase Rules error ko kaise theek karein?

Firebase Console → Firestore Database → Rules ya Storage → Rules kholein, rules verify karein aur Publish karein. App khud server security rules ko change nahi kar sakti.

Account Access

Sign out karne ke liye neeche wala button use karein. Logout ke baad dobara login kar sakte hain.
