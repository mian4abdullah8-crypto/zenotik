Firebase Console → Authentication mein Email/Password aur Google enable karein. Authorized domains mein apni website ka domain add karein.

Video, photo or DP upload issue

Firebase Storage enable karein, bucket name check karein aur secure Storage Rules publish karein. User logged in hona chahiye.

Posts, saved videos or private posts

Firestore Database aur rules mein apni posts ko update karne aur apne user document ko update karne ki permission honi chahiye.
